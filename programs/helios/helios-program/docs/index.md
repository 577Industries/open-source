## About this site

This is the landing page for HELIOS, 577 Industries' research program on calibrated, provenance-tracked space-weather decision intelligence. Each artifact card above leads to that project's folder, or for the schema to its repository.

For technical context on each artifact, see the per-artifact **Review Packs** in the nav. The **OSF Pre-Registration Template** is the text to file before any hold-out evaluation runs; it has not been filed.
